# TS18 diagnostics reference

The raw `TS18_diagnostics.zip` archive is intentionally not committed here.

Use the redacted summaries instead:

- `docs/evidence/ts18-device-profile/s9863a1h10-android10-termone-2026-05-17.md`
- `docs/TS18_INSTALLATION_CONSTRAINTS.md`
- `docs/CODEX_TS18_DEVICE_CONTEXT.md`

The raw archive contained local app-shell output, package lists, selected dumpsys output, storage mounts, USB/ADB properties, and filtered TS18/Topway/DoFun/ZLink hints captured from the actual target device.

Do not add unredacted raw diagnostics to git unless a maintainer explicitly asks for a small, reviewed fixture.
